# Lecture 5 – Fourier Assignment

This folder contains MATLAB exercises on Fourier Series, FFT, spectral leakage, DTFT and DFT.

## Exercises

### Exercise 1 – Build a Square Wave from Harmonics
Approximate a square wave using odd harmonics and compare H = 1, 3, 9 and 25.

### Exercise 2 – Find Two Frequencies with the FFT
Create a signal containing 15 Hz and 40 Hz and identify both frequencies using the FFT.

### Exercise 3 – Investigate Spectral Leakage
Compare one-second and four-second recordings and investigate zero-padding.

### Exercise 4 – Compare the DTFT and DFT
Compare the DTFT with the 4-point and 64-point DFT of the sequence [1 1 1 1].
